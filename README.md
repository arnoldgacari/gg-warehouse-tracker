
# 📦 Multi-Warehouse Inventory Tracker

A modern, full-stack inventory management web application built to track, manage, and transfer stock quantities seamlessly across multiple warehouse locations in real time.

## ✨ Key Features

* **Relational Inventory Views:** Dynamically fetches and displays stock levels joined with product details (SKU, name, price) and warehouse locations.
* **Quick Stock Adjustments:** Instantly increment or decrement inventory counts directly from the UI using secure Next.js Server Actions.
* **Inter-Warehouse Transfers:** Shift stock quantities between locations with built-in validation preventing negative stock or invalid matching.
* **Secure Database Operations:** Powered by Supabase PostgreSQL with server-side rendering (SSR) integration.

## 🛠️ Tech Stack

* **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
* **Backend:** Next.js Server Actions
* **Database & Auth:** Supabase (PostgreSQL)
